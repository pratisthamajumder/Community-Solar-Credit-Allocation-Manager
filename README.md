# GitHub Copilot Code

This folder contains documentation and evidence for the GitHub Copilot activity.

## Files

- `Copilot_Prompts.md` – prompts to use during the activity.
- `Copilot_Code_Notes.md` – records what was generated, changed, tested, and verified.

## Actual Evidence Required

After performing the activity, add the actual:

- Copilot interaction screenshots.
- Copilot-generated/refined source code.
- Test output/screenshots.

Do not claim that code was generated by Copilot unless the activity was actually performed.
