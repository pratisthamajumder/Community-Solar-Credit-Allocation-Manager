# Project Creation Screenshots

This folder is reserved for **actual screenshots from the student's GitHub/project environment**.

Recommended screenshots, subject to the official lab requirements:

1. `01_GitHub_Repository_Created.png`
   - Shows the repository name and owner.

2. `02_Repository_Structure.png`
   - Shows the final repository folder/file structure.

3. `03_Project_Setup.png`
   - Shows the actual project setup or initialization required by the lab.

4. `04_Commit_History.png`
   - Shows commits demonstrating the work.

## Important

Do not upload fabricated screenshots. Capture the screenshots yourself after creating/pushing the repository.
