# GitHub Copilot Code Notes

## Activity

The GitHub Copilot activity should demonstrate how Copilot was used to assist with implementation and testing of a feature related to the Community Solar Credit Allocation Manager.

## Record the Following

### 1. Prompt
Copy the actual prompt submitted to GitHub Copilot.

### 2. Generated Suggestion
Save the actual code suggested by Copilot.

### 3. Student Review
Document:
- What the generated code does.
- Whether the logic matches the requirements.
- Any changes made manually.
- Any validation or security improvements.

### 4. Testing
Record:
- Test case.
- Expected result.
- Actual result.
- Pass/Fail.

### 5. Refinement
Document any changes made after testing.
